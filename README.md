Se debe ejecutar el archivo "main.py" el cual contiene el código, que incluye importaciones, funciones y condicionales que permiten la ejecución del menú interactivo.
dentro del paquete blog encontramos 4 módulos principales:

menu: contiene la función que permite ver la interfaz inicial, además de consultar y guardar la opción que el usuario elija.

operaciones: contiene las tres funciones que se encargan de la búsqueda y devolución de los posts, como buscarlos por tag, título, o simplemente mostrar todos los posts.

datos: guarda todas las estructuras de datos que son necesarias para las funciones del programa, guarda principalmente los posts, pero también contiene otros datos como el diccionario "perfil_autor", la tupla de "estados_post" y el set de "etiquetas_blogs"

validaciones: contiene la fucnión que administra la validación de los posts, verifica que el post cumpla con los parámetros requeridos.
